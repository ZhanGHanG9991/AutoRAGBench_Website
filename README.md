# RAGEngBench project page

Static site for RAGEngBench, served by GitHub Pages from the `main` branch root.

- `index.html` — leaderboard, scoring protocol, setup, observations, citation
- `traces/` — timestamped GPT-6.1 Sol (Codex CLI) build traces for all nine benchmarks
- `assets/data.js` — all numbers on the page, generated by `site_build/build_data.py` in the research repo
- `assets/common.js` — `window.SITE` holds the GitHub link, paper link and author list

No build step: edit, commit, push. Preview locally with `python -m http.server` in this folder.
